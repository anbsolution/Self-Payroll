# Self Payroll — Website / PWA

Offline-first website version of Self Payroll.

## Included
- Punch IN / OUT
- Daily attendance
- Monthly attendance table
- Salary slip
- Profile and salary settings
- JSON backup / restore
- Print / Save as PDF
- Web Share when supported
- Dark mode
- PWA install support
- Service-worker offline cache
- GitHub Pages deployment workflow

## GitHub Pages
Upload these files to the repository root and push to `main` (or `master`).
Then in **Settings → Pages**, select **GitHub Actions** as the source if GitHub asks.

For a repository named `Self-Payroll` under the account `anbsolution`, the project URL will normally be:
`https://anbsolution.github.io/Self-Payroll/`

## Important
This version stores records in the browser's local storage. It does not provide cross-device cloud synchronization. A backend can be added later without changing the four main sections.
